## 💛 ¿Qué es esto?

Este es un regalo digital para el cumpleaños número **21** de **María Alejandra**, creado por su novio **Antony Salcedo**. Es una Single Page Application (SPA) temática de **Pompompurin** (Sanrio) que reúne fotos, una carta de amor, música y juegos interactivos en un solo lugar.

> *"21 vueltas al sol siendo la luz más bonita que existe."*

---

## ✨ Características

| Sección | Descripción |
|---|---|
| 🏠 **Pantalla de Carga** | Animación de Pompompurin con barra de progreso mientras se prepara el regalo |
| 📸 **Galería Dinámica** | Fotos organizadas por categorías con filtros interactivos y lightbox con mensajes románticos únicos |
| 💑 **Nuestra Historia** | Timeline visual del inicio de la relación con fotos ampliables |
| 🌹 **El Primer Ramo** | Sección especial conmemorando las primeras flores |
| 💛 **21 Razones** | Tarjetas animadas con 21 razones de amor — una por cada año |
| 🎮 **Quiz del Amor** | Juego interactivo de 7 preguntas sobre la relación |
| 💌 **La Carta** | Pergamino digital con la carta de cumpleaños completa |
| 🎵 **Reproductor de Música** | Widget flotante con 9 canciones, carátulas y controles |
| 💕 **Corazones Flotantes** | Emojis animados que flotan por toda la página |

## 🎨 Diseño

- **Tema:** Pompompurin × Romance
- **Paleta:** Amarillos crema `#FFF9B0` · Marrones chocolate `#63432D` · Rosa pastel `#FFB6C1`
- **Tipografías:** [Comfortaa](https://fonts.google.com/specimen/Comfortaa) + [Dancing Script](https://fonts.google.com/specimen/Dancing+Script)
- **Estilo:** Bordes redondeados, glassmorphism sutil, animaciones suaves, scroll reveal

## 🚀 Despliegue

Esta página está diseñada para ser desplegada en **GitHub Pages**:

1. Sube el repositorio a GitHub
2. Ve a **Settings** → **Pages**
3. Selecciona la rama `main` y la carpeta `/ (root)`
4. ¡Listo! Tu página estará en: `https://tony-ssr.github.io/Feliz-cumplea-os-21-mi-florcita/`
